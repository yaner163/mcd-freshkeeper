# 麦门保鲜员（McMen Freshkeeper）

> 麦当劳的券过期得比你想的快。这个 Skill 每天替你扫一遍卡包和积分，把「今天不作废就白瞎」的东西顶到最前面，然后给你能执行的处置方案。

基于 [麦当劳中国官方 MCP 服务](https://github.com/M-China/mcd-mcp-server) 开发 —— 2026 麦当劳程序员创意开发大赛参赛作品。

## 为什么做这个

领券大家都会，但**过期**这件事没人管。

实测一个普通用户卡包：券的有效期大量集中在 1–2 天，隔三差五就有一张「今天不用就作废」。很多人不是不想用，是**根本不知道它快过期了**——打开 App 看到几十张券，第一反应是划走而不是核对有效期。积分同理：年底一堆分静默清零。

现有教程大多教「怎么领券」，没教「怎么别让券烂在手里」。这个 Skill 补的就是这一段：**领券之后的后半程管理**。

## 它能做什么

| 模式 | 你说 | 它做 |
| --- | --- | --- |
| 🩺 临期体检 | "体检一下" | 扫卡包 → 按剩余天数分档 → 输出到期排序表 + 逐张处置建议 |
| 🔥 今日清仓 | "今天有什么快过期的" | 只挑 0–1 天的券，凑成一份「今晚必须解决」清单 |
| 🪙 积分保鲜 | "我的积分还有吗" | 查积分账户 → 定位临期积分 → 推荐 7 天内该换什么 |
| 📅 晨间播报 | "麦麦早报" | 今日活动 + 新券 + 临期资产预警，一屏说完（可挂定时任务） |
| 🧮 用掉它 | "这张券怎么用最划算" | 拉门店菜单 → 试算组合 → 给到店/麦乐送两条路径 |

**核心原则：只诊断，不擅自花钱。** 脚本永远不调用下单和兑换接口；涉及资金的动作一律先出方案、等确认。

## 快速开始

### 1. 申请 MCP Token

前往 [open.mcd.cn/mcp](https://open.mcd.cn/mcp) → 手机号登录 → 右上角「控制台」→「激活」→ 复制 Token。

### 2. 配置 MCP 连接器

WorkBuddy：左侧边栏【专家·技能·连接器】→【连接器】→ 右上角【自定义连接器】→【配置MCP】：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer YOUR_MCP_TOKEN"
      }
    }
  }
}
```

> 记得把 `YOUR_MCP_TOKEN` 换成真实 Token。脱敏示例见 `mcp-config.example.json`。

### 3. 安装 Skill

把 `SKILL.md` 与 `references/` 复制到你的技能目录：

- **WorkBuddy**：`~/.workbuddy/skills/mcmen-freshkeeper/`
- **其他 Agent**：放入对应的 skills 目录（SKILL.md 为通用格式，不绑定框架）

### 4. 跑离线自测（可选，验证脚本环境）

```bash
python scripts/coupon_auditor.py --self-test
```

不需要 Token，不联网，**47 项断言**全过即环境正常。其中 12 项是 2026-10-10 通过官方 MCP 实测数据的回归用例。

## 脚本用法

`scripts/coupon_auditor.py` 是本项目的可运行核心，纯标准库、离线、不需要 Token。

```bash
# 内置样例，直接看效果
python scripts/coupon_auditor.py --demo

# 喂真实 MCP 返回（顶层支持数组或 {"coupons":[...],"points":{...}}）
python scripts/coupon_auditor.py --input my_coupons.json

# 机器可读输出，便于接后续自动化
python scripts/coupon_auditor.py --input my_coupons.json --json

# 指定基准日期（回测历史数据时用）
python scripts/coupon_auditor.py --demo --today 2026-10-10
```

## 分档规则

| 档位 | 剩余 | 是否必须行动 |
| --- | --- | --- |
| P0 今天到期 | 0 天 | 是 |
| P1 明天到期 | 1 天 | 是 |
| P2 三天内 | 2–3 天 | 是 |
| P3 本周内 | 4–7 天 | 顺手 |
| P4 还早 | > 7 天 / 有效期未知 | 否 |

面额低于 ¥10 的券会额外标注「不值得专门跑一趟」，避免为了省三块钱浪费一趟。

## 定点券：实测发现的一类特殊券

2026-10-10 实测麦当劳 MCP 返回的有效期不止是日期区间，还有**时段和星期限制**：

```
2026-10-11 05:00-2026-10-11 10:29 周日 05:00-10:29
```

这类「定点券」只在指定日期的指定时段可用。实测中同一张 ¥29.9 早餐券有 3 张，分别锁定在 10-11、10-17、10-18 的早餐时段。

**如果不识别它，只按「还剩 1 天」提醒，你会明天下午去店里，发现券已经失效了。** 所以本项目会单独标出具体日期 + 时段：

```
| 剩余 | 档位 | 券名 | 面额 | 可用限制 |
| --- | --- | --- | --- | --- |
| 1 天 | P1 | 人气麦旋风买一送一 | ¥15 | 时段 10:00-22:00 |
| 1 天 | P1 | 巧克力味厚松饼猪柳蛋套餐 | ¥29.9 | **仅 2026-10-11 05:00-10:29** |
```

## 目标用户

- 麦当劳常客但懒得翻卡包的人
